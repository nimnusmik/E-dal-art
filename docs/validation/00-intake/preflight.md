# 프리플라이트 점검 — 이달아 (2026-09-21)

**모드:** Knowledge-Based — 웹 검색 미사용. 모든 항목 **[Knowledge-Based — 실시간 데이터 아님, 직접 검증 필요]**, 신뢰도 1단계 하향 적용.

## 1. 지배적 기존 솔루션 점검
⚠️ "네일 테크용 AI 시안 생성" 자체엔 지배적 사업자 없음 — 그러나 **대체재가 지배적**:
- **Pinterest / Instagram / TikTok** — 네일 인스포의 사실상 표준. 무료, 습관화, 네트워크 효과. (신뢰도: 높음)
- **Perfect Corp (YouCam Nails)** — 상장사가 운영하는 AR 네일 트라이온. "손님 손에 미리 보여주기" 니즈를 이미 공략 중. (신뢰도: 중간)
- **GlossGenius($24~48/mo)·Fresha·Booksy** — 네일 테크의 지갑을 이미 점유한 업무 도구(예약·결제). 시안 생성 기능은 없음 → 여기가 빈 공간. (신뢰도: 중간)

## 2. 선행 실패 사례 점검
⚠️ 유명 펀딩 스타트업의 공개 실패 사례는 알지 못함. 대신 앱스토어에 소규모 "AI nail art" 앱이 다수 명멸 — 단일 기능 AI 이미지 앱의 낮은 리텐션은 창업자가 여친사진코치 리서치에서 직접 확인한 패턴과 동일. (신뢰도: 중간)

## 3. 규제·법적 즉사 요인
✅ 없음. 단, 손님 사진을 해외 리전(BytePlus)으로 전송 시 개인정보 처리방침 반영 필요 — 이미 README에 인지됨.

## 추가 발견 — 문제 가설에 대한 지식 기반 교정
**[Knowledge-Based]** 영어권 네일 테크 커뮤니티(r/Nailtechs 등)에서 반복 관찰되는 실제 고통은 "시안을 못 짜겠다"가 아니라:
1. 손님이 **실현 불가능한 인스포 사진**을 들고 옴 (다른 손톱 모양·길이, 다른 기법) → 기대치 조율이 고역
2. 애매한 사진 여러 장을 들고 "이 느낌으로" → **번역(사진→실행 가능한 시안)** 이 고역
3. 시안이 아니라 **시간·가격 협상**이 고역

→ 이달아의 "사진 2~3장 → 구체적 시안 콜라주"는 2번과 정확히 맞물림. 창업자 가설("시안 창작이 고역")과는 미묘하게 다름 — **창작 도구가 아니라 상담 도구로 포지셔닝될 때 통할 가능성이 높음.**

⚠️ **역방향 리스크:** AI 생성 네일은 물리적으로 재현 불가한 디자인(해부학적으로 틀린 손, 불가능한 아트)을 자주 만듦. 아티스트가 손님 앞에서 보여줬다가 재현 못 하면 도구 신뢰가 즉사함. 프리랜서 아티스트 3명에게 생성 결과물을 보여주고 "이거 실제로 시술 가능한가"를 반드시 확인할 것.
