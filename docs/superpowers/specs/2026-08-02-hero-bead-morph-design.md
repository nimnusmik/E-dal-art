# 히어로 구슬 변신 연출 — 설계 문서

- 날짜: 2026-08-02
- 상태: 사용자 승인 (대화에서 A/A/B 선택 확정)

## 목적

No.02 섹션(BeadMorph)의 구슬 애니메이션을 히어로로 통합한다.
영감 사진 4장이 구슬이 되어 히어로의 맨손을 감싸고 돌다가 손톱으로
스며들면, 맨손톱이 이달의 디자인 손톱으로 재탄생하는 연출을
무한 루프로 보여준다. "영감 한 장 → 시안"이라는 제품 가치를
첫 화면에서 즉시 전달하는 것이 목표.

## 확정된 결정

| 결정 | 선택 |
|---|---|
| 변신 후 손 이미지 | Gemini 생성 (`hand.webp` 입력, 같은 손·같은 포즈, 손톱만 디자인 적용) |
| 기존 No.02 BeadMorph 섹션 | 삭제 (중복 제거, 뒤 섹션 번호 당김) |
| 재생 방식 | 무한 루프 (완성 상태 길게 정지로 산만함 완화) |

## 1. 에셋 생성 (선행 작업, 품질 게이트 있음)

- `scripts/`에 일회성 생성 스크립트 추가.
- 입력: `public/hero/hand.webp`. 출력: `public/hero/hand-after.webp`.
- 프롬프트 규칙 (2026-07-31 확정 품질 피드백 준수):
  - 금지 모티프 목록 유지 (도넛·리본 등 식상한 반복 모티프 금지)
  - 트렌드 키워드는 질감·효과 중심으로만 서술 (음식·파츠 명사 금지)
  - 손톱이 손가락에 자연스럽게 붙어 있을 것
  - 손 포즈·구도·피부톤은 원본과 동일해야 함 (정렬 필수)
- **게이트:** 원본과 겹친 비교 이미지로 정렬 검증. 손톱 위치가
  어긋나면 재생성. 통과 전에는 2단계 구현에 착수하지 않는다.

## 2. 히어로 연출 (핵심)

`HeroHand`에 BeadMorph의 궤도·소용돌이 계산(rAF 타임라인, 타원 궤도,
위상 흔들림)을 이식해 하나의 루프 타임라인으로 만든다.

루프 1회의 단계:

1. **정지 (약 2초):** 맨손 + 영감 카드 4장 (현재 히어로 모습)
2. **소용돌이 (약 3초):** 카드가 구슬로 변해 손 주위 타원 궤도를 돌며 섞임
3. **흡수 + 플래시:** 구슬이 손톱 쪽으로 빨려 들어가며 은은한 광
4. **재탄생:** 손톱 부위 중심의 원형 리빌(clip-path)로
   `hand-after.webp`가 드러남 — 맨손톱 → 디자인 손톱
5. **완성 정지 (약 4초):** CTA를 읽을 시간 확보
6. **복귀 (약 0.8초):** 부드럽게 맨손 + 카드 상태로 페이드, 반복

접근성·성능:

- `prefers-reduced-motion`: 애니메이션 없이 완성된 손 정지 이미지만 표시
- `document.visibilitychange`: 탭이 백그라운드면 루프 일시정지
- 두 손 이미지는 같은 크기·같은 위치로 겹쳐 배치 (정렬 전제)

## 3. No.02 섹션 삭제

- `StoryLanding`에서 해당 섹션 제거, 뒤 섹션 번호 당김 (No.03 → No.02 …)
- BeadMorph 전용 CSS(`morph-*`) 정리
- `ba-before.webp` / `ba-after.webp`가 다른 곳에서 미사용이면 삭제

## 4. 검증

- 개발 서버 + Playwright로 루프 각 단계(카드 → 구슬 → 변신 → 완성)
  스크린샷 확보, 사용자 확인
- `npm run typecheck`, `npm run test` 통과
- reduced-motion 에뮬레이션으로 정지 이미지 폴백 확인
