## 목표

현재 잡지(에디토리얼) 스타일 랜딩을 참조 이미지의 비주얼 언어로 전면 교체한다.
단, 다음 두 가지는 반드시 유지한다:

1. **히어로 손 변신 애니메이션** — 영감 카드 4장이 구슬이 되어 손을 돌다 손톱으로 스며드는 무한 루프 (`heroMorph.ts` 타임라인)
2. **사진 주입 툴** — `InspirationTray`(최대 3장) + `OptionsPicker` + 생성 CTA, `#tool` 앵커 포함 (page.tsx의 toolSlot 주입 패턴)

## 확정 결정 (사용자 답변)

| 질문 | 결정 |

| 구현 전략 | 랜딩 신규 컴포넌트 + 디자인 토큰 교체, 내부 화면은 토큰만 물려받음 |

## 비주얼 언어

- **배경**: 푸른 하늘 + 초원 사진 → `public/landing/`에 webp로 저장. 히어로·갤러리·풋터 CTA 3개 섹션에 풀블리드
- **타이포**: 대형 컨덴스드 헤드라인, 흰색 + 진한 아웃라인/그림자. 영문 디스플레이 Archivo Black급, 한글 Pretendard Black급
- **컴포넌트 문법**:
  - 흰 라운드 카드 + 모서리 컬러 블롭 (통계·후기)
  - 파스텔 필(pill) 배지 — 5색 팔레트 (핑크·블루·옐로·그린·퍼플)
  - 틸트된 폴라로이드 카드 + 맥 창 점 3개 (갤러리)
  - 도트 그리드 종이 배경 + 왼쪽 스프링노트 코일 장식 (흰 섹션)
- **제거**: 바코드, 커버라인, 티커, 세리프 마스트헤드, 고스트 발행호 숫자 등 잡지 전용 장치

## 페이지 구성 (위→아래)

1. **TopBar** — 미니 상단 바: 이달아 로고 + 필 배지 내비
2. **Hero** (초원 배경) — 필 배지("K-Nail Trend" / "매월 발행" / "Available") + 대형 헤드라인 + **손 변신 무대** (heroMorph 애니메이션 그대로) + 스크롤 큐
3. **Stats** (흰 배경 + 도트 그리드) — 인트로 카피 + 제품 사실 카드 4장:
   - **5종** 시안 동시 생성
   - **3장** 사진이면 충분
   - **100%** AI 검수 통과작만 노출
   - **매월** 새 호 발행
4. **Gallery** (초원 배경) — 시안 예시 폴라로이드 카드 (기존 영감/결과 이미지 재사용, 틸트 배치)
5. **Services** (흰 배경) — 이용 흐름 5행 파스텔 필: 사진 분석 → 5종 변주 → AI 검수 → 착용샷 → 월간 발행 (기존 HowItWorks 대체)
6. **ToolSection** (`#tool`) — 사진 주입 툴을 큰 흰 라운드 카드로 리스킨. page.tsx의 toolSlot이 그대로 들어옴 (트레이·옵션·CTA·잔여횟수·에러 토스트)
7. **Testimonials** (흰 배경) — "이렇게 쓰여요" 페르소나 카드 3장 (원장님/네일 러버 예상 사용 장면, 실명 후기로 오인되지 않게 명시)
8. **Faq** — 산개된 파스텔 필 질문들: 하루 몇 회? / 어떤 사진이 좋아요? / 무료인가요? / 시안은 저장되나요? 등
9. **FooterCta** (초원 배경) — 초대형 타이포 "이달의 네일, 먼저 만나요" + `#tool` CTA + 미니 풋터 바

## 에러·접근성

- 기존 동작 보존: 에러 토스트, 잔여 횟수 노출 규칙(≤10), rate-limit 마감 화면
- `prefers-reduced-motion` 시 손 변신 정지·완성컷 즉시 노출 (기존 로직 유지)
- 초원 배경 위 텍스트는 아웃라인/그림자로 대비 확보 (참조 이미지와 동일 기법)
- 폴라로이드·필 장식은 `aria-hidden`, 의미 있는 이미지에만 alt
