# 히어로 개편 — "제시하는 손 + 영감 사진" (Hero Hand Inspiration)

- 날짜: 2026-07-25
- 대상: 첫 화면(랜딩) 히어로. 현재 `components/story/HeroRing.tsx`(3D 회전 링)를 대체
- 상태: 설계 승인됨 (구현 계획 대기)

## 1. 배경 & 문제

현재 히어로는 네일 팁 사진 10장을 3D로 회전시키는 링이다. 문제:

1. 팁 이미지가 **흰 배경 사각형 사진**(`#f6f6f6`, 불투명). 지면 배경 크림색(`#fcfaf7`)과
   미묘하게 안 맞아 "흰 사각 조각이 떠 있는" 느낌.
2. `border-radius` + `box-shadow`로 각 컷이 "둥근 카드"처럼 처리됨. 주석의 의도
   ("프레임 없는 화보 컷")와 결과가 어긋남.
3. 감각·의도가 약하고 프로젝트 정체성(영감 사진 → 네일)이 첫 화면에서 안 드러남.

## 2. 목표 컨셉

참고 이미지(손 둘레에 사물이 번호·라벨과 함께 떠 있는 편집형 인덱스)를 차용한다.

- **중심**: 네일을 입히지 않은 **맨손(제시하는 손)** 실사 이미지. 영감 사진을 펼쳐 보이는 제스처.
- **둘레**: "사용자가 올릴 법한 영감 사진" 4장이 **번호 + 한글 라벨 + 가는 연결선**과 함께 떠 있음.
- **메시지**: "이런 일상/감성 사진 한 장 → 이달의 네일". 툴의 입력(영감 사진)을 첫 화면이 예고.

매거진 뼈대(매스트헤드·발행호 오버라인·세리프 h1·서브카피·CTA·Scroll 큐)는 **그대로 유지**하고,
`.ring-stage`가 있던 자리만 손 무대로 교체한다.

## 3. 에셋

### 3.1 중심 손 이미지
- 경로: `public/hero/hand.webp` (필요 시 모바일 축소본 `hand@sm.webp`)
- 생성: AI 생성. `scripts/generate-samples.mts` 패턴을 따르는 신규 스크립트로 프로젝트
  파이프라인(`lib/provider.ts`)에서 뽑는다. 프롬프트는 구현 단계에서 확정 작성.
  방향: 크림색(`#fcfaf7`) 무광 배경, 손등/손바닥이 펼쳐진 제시 제스처, **네일 아트 없음(맨손)**,
  자연광 스튜디오, 세로 구도, 손목 아래 페이드아웃.
- 구현 초기에는 임시 플레이스홀더(회색 실루엣)로 레이아웃부터 확정한 뒤 실제 이미지로 교체.

### 3.2 둘레 영감 사진 (파일럿: `pilot/` 4장)
| 원본 | 내용 | 제안 라벨 |
|---|---|---|
| `_ (9).jpeg` | 타투 플래시(윙 하트·클로버·堕落天使) | 타투 플래시 |
| `_ (12).jpeg` | 몽환 수채 6컷(꽃병·달·별) | 몽환 파스텔 |
| `_ (13).jpeg` | 페어리코어 파스텔(핑크 바니) | 페어리코어 |
| `_ (14).jpeg` | 엔젤 윙 파스텔 | 엔젤윙 |

- 처리: 정사각 크롭(`object-fit: cover`)으로 리사이즈 후 webp 변환 → `public/hero/insp/`.
- **주의(저작권)**: 파일럿 4장은 워터마크가 있는 제3자 이미지(@ethyl.alcohol.tt, 小红书호 등).
  자리표시용으로만 사용하며, 공개 배포 전 소유/라이선스한 이미지로 교체해야 한다.

### 3.3 시각 처리 결정
- 영감 사진은 **배경까지 꽉 찬 감성 이미지**(색·비율 제각각)이므로 `mix-blend-mode: multiply`
  "흰 배경 녹이기"는 **적용하지 않는다**(컬러 배경이 탁해짐).
- 대신 **깔끔한 편집형 액자**: 균일 정사각 크롭 + 헤어라인 프레임 + 번호 + 라벨 + 연결선.
  4장이 어수선하지 않고 감각적 인덱스로 읽히게 한다.

## 5. 컴포넌트/데이터 구조

- 신규 `components/story/HeroHand.tsx` — `HeroRing`을 대체. 프레젠테이션 전용.
- 신규 `components/story/heroInspo.ts` — 컷 배열. 사진 추가/교체가 한 줄 수정으로 끝나게:
  ```ts
  export interface InspoCut {
    src: string;      // '/hero/insp/tattoo.webp'
    no: number;       // 2
    label: string;    // '타투 플래시'
    at: 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right'; // 미리 정의된 앵커
  }
  ```
  각 앵커는 CSS에서 미리 정의된 위치 → 좌표 노가다 없음.
- `StoryLanding.tsx`: `HeroRing` import/사용 → `HeroHand`로 교체.
- `app/globals.css`: `.story-hero`·`.hero-*`는 유지. `.ring-*`(약 170~216행, 747~761행,
  761행 모션 저감) 규칙을 **삭제**하고 `.hand-stage / .inspo-cut / .inspo-line` 규칙으로 교체.
- 삭제: `components/story/HeroRing.tsx`, `public/samples/ring-*.webp`(10장), 이를 만들던
  `scripts/generate-samples.mts`의 ring 관련 부분(다른 용도가 없으면 정리).

## 6. 모션 & 인터랙션

- 회전 애니메이션 제거. 정적 무대 + **미묘한 진입 모션**: 손 페이드인 → 컷들이 0.1s씩 시차
  translateY+opacity로 떠오름.
- 데스크톱 hover: 해당 컷 살짝 확대 + 연결선 강조.
- `@media (prefers-reduced-motion: reduce)`: 진입 모션·hover 모션 생략(즉시 표시).

## 7. 접근성

- 손 이미지: 장식용 → `alt=""` 유지 가능하나, 무대 전체에 `aria-label`로 의미 제공.
- 각 영감 컷: `alt`에 라벨 제공("영감 예시 — 타투 플래시").
- 번호/라벨 텍스트는 실제 텍스트로(이미지 아님) 렌더 → 스크린리더·검색 노출.

## 8. 테스트/검증

- 기존 vitest 스모크 유지(깨지지 않게).
- 브라우저로 데스크톱/모바일 전후 스크린샷 비교(gstack 또는 playwright).
- 검증 순서: (1) 플레이스홀더로 레이아웃 확정 → (2) 영감 4장 삽입 → (3) AI 손 이미지 교체.

## 9. 범위 밖 (YAGNI)

- 영감 컷 클릭 → 실제 툴 입력 자동 연동(추후 별도).
- 컷 개수 동적 가변(당분간 4장 고정 앵커).
- 손 이미지 다국면/애니메이션.

## 10. 미해결/구현 시 확정

- AI 손 이미지 최종 프롬프트 문구.
- 영감 라벨 최종 문구(현재 제안값 사용, 사진 확정 시 조정).
- 파일럿 이미지 → 라이선스 보유 이미지 교체 시점(공개 배포 전).
