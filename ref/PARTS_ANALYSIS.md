## 1. 핵심 결론 (요약)

1. 파츠 어휘는 7계열 30여 종이지만, **사용자 정수(trendy + new)는 그중 8종만 쓴다**:
   실버 볼, 진주, 별(젬/메탈), 하트 젬, 리본, 단추, 3D 장미/플라워, 라인스톤 십자가.
2. 진짜 변별력은 종류가 아니라 **배치 구조**다. 같은 실버 볼도:
   - 구조 없이 흩뿌리면 → 파일럿에서 문제가 된 "남발" (산개 구조 S7)
   - 십자가·하트 모양으로 배열하면 → new/ 폴더의 세련된 "스터드 드로잉" (S2)
   **→ "은색 동그라미 금지"가 아니라 "산개 금지, 구조 지정"이 정답.**
3. 파츠 없는 디자인도 다수 (trendy 12장 중 다수, 5615~5617) — "파츠 없음"도 정식 옵션.

## 5. 생성 프롬프트 템플릿 (구조별 영문)

- S1: `The whole set stays clean: exactly one tip carries a single {PART}; every other tip has no metal, no gems.`
- S2: `On tip #{N}, tiny silver microbeads are arranged in a precise {cross/heart/V} outline, like pixels forming a shape. No other tip has any metal.`
- S3: `On tip #{N}, small dots/microbeads trace along the french boundary line only.`
- S4: `One {pearl/silver bead} sits exactly ON the french boundary line of tip #{N}, like a belt buckle.`
- S6: `Tip #{N} is the centerpiece: one {3D rose / heart gem} at its center. All remaining tips are painted-only.`
- 공통 금지문 대체(긍정문): `Metal appears only where specified above.` (※ "no studs everywhere" 같은 부정문보다 효과적)

## 5-1. 파츠 물리 법칙 (생성 프롬프트 필수 첨부 — 2026-08-03 확정)

천체 골드 세트에서 참이 목걸이 펜던트처럼 "매달려" 렌더링되는 오류 → 3회 반복 실험으로 해결. 확정 규칙:

1. **"charm"이라는 단어를 쓰지 마라** — 단어 자체가 펜던트 고리(jump ring)의 사전 지식을 부른다.
   반드시 **"flat metal STUD shaped as ..." / "metal inlay" / "embossed metal sticker"** 로 지칭.
   (anchor→닻, glazed donut→도넛과 동일한 단어 함정 계열)
2. 물리 서술은 긍정문으로: `SOLID CAST shape with a clean closed outline, exactly the motif silhouette
   and nothing more` — "no jump rings" 같은 부정문은 뚫린다 (실험으로 확인).
3. 공통 첨부 블록 (`PARTS_PHYSICS`, scripts/pilot-interpret.mts):
   flat + flush on surface + sealed under clear gel + glued like a sticker + fully inside the nail outline.

검증: charm(고리 3/3) → charm+긍정문(고리 2/3) → **stud+긍정문(고리 0/3, 완전 해결)**.
