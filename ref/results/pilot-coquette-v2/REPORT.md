# 2차 파일럿 결과 — 구조 문법 적용판 (2026-08-02)

변경: anchor→hero 다의어 제거 / 개수 강제 제거 / 부정문→긍정문 / 파츠 구조 문법(S-코드) 팁별 명세.
1차와 동일 슬롯(패턴 5 × 팔레트 5) + 파츠 플랜 5종(S1 진주/S2 스터드 드로잉/S6 장미/없음/S4 경계선 스터드).

|---|---|---|---|---|---|
| set-01 | S1 진주 1개 | 3.5/4 | ✓ 정확히 1개 | 조건부 통과 | 블랙 경계선이 팔레트 외 (저용량이라 경미) |

## 1차 vs 2차 비교

| 지표 | 1차 | 2차 |
|---|---|---|
| 완전 통과 (4/4) | 2/10 (20%) | **4/10 (40%)** |
| 통과+조건부 (사용 가능권) | 6/10 | **9/10 (90%)** |
| 탈락 | 4/10 | 1/10 |
| 닻(⚓) 오렌더링 | 7/10 | **0/10** ← anchor 제거 효과 |
| 파츠 산개(남발) | 상시 | **0/10** ← 구조 명세 효과 |
| 옴브레 등장 | 1건 | 0건 ← 긍정문 효과 |
| 파츠 구조 준수(형태 기준) | — | 10/10, 개수까지 정확 6/10 |

## 남은 실패 모드 (경미)

1. **개수 드리프트**: "1개"→2개, "2팁"→3~5팁. 모델의 수 세기 한계 — 검수에서 개수만 세면 걸러짐.
2. **영감 이미지 색 번짐**: 팔레트에 없는 블랙/버건디가 영감 사진에서 유입. → 검수 or 영감 이미지 팔레트 매칭.
3. **Angel 레터링 간헐 중복** (2/10).
4. 쉐입이 아몬드보다 오벌로 나오는 경향 (스타일 무관, 경미).

## 부록: 레터링 슬롯 테스트 (2026-08-03, ref/results/pilot-lettering/ 5세트)

"Angel" 하드코딩 반복 문제 수정 — 레터링을 테마 연동 슬롯으로 전환 (`LETTERINGS` 배열, null=레터링 없음).

| 세트 | 단어 | 렌더링 | 1회 제한 | 테마 적합 |
|---|---|---|---|---|
| set-01 | Sugar | ✓ 오탈자 없음 | ✓ 정확히 1팁 | 도트×파스텔에 어울림 |
| set-02 | Honey | ✓ | ✓ | 버터 옐로우와 일치 |
| set-03 | Cherie | ✓ | ✓ | 핑크 깅엄 코케트에 완벽 |
| set-04 | (없음) | — | ✓ 텍스트 0 | 스월 양각 세트 |
| set-05 | Bonbon | ✓ | ✓ | 초코×핑크 디저트 무드에 완벽 |

**5/5 성공. 짧은(4~6자) 흔한 단어는 필기체 렌더링이 안정적이며, "written once, on one tip only" 문구로 중복도 해결됨** (v2 본편에서 2/10이던 중복이 0/5). 향후 디자이너 뇌(세트 플래너)가 세트 컨셉에서 단어를 자동 선택하게 하면 됨 — 단어 풀: Sugar, Honey, Cherie, Bonbon, Dolly, Bisou, Lucky, Merci 등 4~6자 위주.

## 결론

- 구조 문법(파츠 팁별 명세)이 **파츠 남발을 완전히 잡았고**, 다의어 제거가 모티프 오염을 0으로 만듦.
- 사용 가능권 90% → **"4장 생성 + 검수 1차 통과작 노출" 아키텍처면 상용 품질 달성 가능** 판단.
