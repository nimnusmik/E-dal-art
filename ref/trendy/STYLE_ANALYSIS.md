# 트렌디 레퍼런스 스타일 분석 (ref/trendy, 12장)

> 2026-08-02 기준. IMG_6093 ~ IMG_6104 분석.
> 목적: 이 디자이너의 스타일을 "재현 가능한 규칙"으로 뽑아, 이달아(nailspo)에서
> 디자인 생성 프롬프트 / 스타일 태그 / 추천 로직에 그대로 쓰기 위함.

---

## 1. 한 줄 정의

**"시어 누드 베이스 + 파스텔 마이크로 프렌치 + 레트로 소녀 감성(도트·리본·레이스·별) + 절제된 입체 파츠"**
— 코케트(coquette) × Y2K × 일본 갸루의 교집합. 화려하지만 유치하지 않고,
네일의 60~70%를 비워두는 여백이 시그니처.

## 2. 공통 문법 (12장 전체에서 반복되는 규칙)

### 2-1. 베이스: 무조건 "비워둔다"
- 모든 디자인의 바탕은 **시어(반투명) 밀키 누드/핑크** — 유리알처럼 광이 도는 젤 마감.
- 풀컬러로 채우는 손톱은 10개 중 1~2개뿐(포인트 손톱). 나머지는 누드 베이스 위에
  **팁(프렌치) 부분에만** 디자인이 얹힘.
- → 생성 시 핵심 제약: `sheer milky nude base, glossy gel finish, design only on the tip`

### 2-2. 구조: 딥 프렌치 (French tip이 뼈대)
- 디자인의 80%가 프렌치 변형. 팁 경계선이 일반 프렌치보다 깊게(손톱의 1/3~1/2) 내려옴.
- 팁 안에 패턴(도트, 스트라이프, 체크)을 넣는 **"패턴드 프렌치"**가 최다 빈도.
- 경계선은 스마일라인(곡선)이 기본, 가끔 사선/직선 변형.

### 2-3. 컬러 팔레트
| 그룹 | 색 | 비고 |
|---|---|---|
| 주력 파스텔 | 베이비핑크, 베이비블루/민트, 버터 옐로우, 라일락 | 채도 낮고 밝은 "설탕 파스텔" |
| 뉴트럴 | 밀키 화이트, 시어 누드 | 베이스 및 여백 |
| 악센트(소량) | 블랙, 초코 브라운, 버건디 레드 | 도트·별·라인에만 — 전체를 어둡게 하지 않음 |
- 한 세트에 파스텔 2~3색 + 뉴트럴. **비비드 원색·네온은 등장하지 않음.**
- 블랙은 "달콤함을 잡아주는 간장 역할" — 도트나 스트라이프로만 소량 사용 (IMG_6097, 6098, 6103).

### 2-4. 패턴 어휘 (빈도순)
1. **폴카 도트** — 시그니처 중의 시그니처. 크기 다양(마이크로~빅도트), 팁 안쪽에 배치.
2. **스트라이프** — 가는 2~3줄 라인, 파스텔 2색 조합 (핑크×블루 등).
3. **깅엄 체크 / 타탄 체크** — 파스텔 톤 (IMG_6100 하늘색 체크, IMG_6102 핑크 체크).
4. **별(스타)** — 오라 스타, 크롬 별, 별 모양 파츠. Y2K 요소 담당.
5. **레이스 프릴 라인** — 프렌치 경계선을 레이스 무늬로 처리 (IMG_6100, 6104). 코케트 요소.
6. **필기체 레터링** — "Angel" 등 흘림체 스크립트를 손톱 하나에 크게 (IMG_6095, 6098, 6099).
7. **손그림 플라워** — 복고풍 벚꽃/장미 일러스트 (IMG_6093 2행, IMG_6100 장미).
8. **소용돌이(스월)·하트 낙서** — 자유곡선 드로잉 (IMG_6104 마지막 행).

### 2-5. 파츠(3D 장식) 사용 규칙
- **실버 미니 볼(뷸렛) 스터드** — 가장 자주. 1~3개만 점처럼 콕콕.
- **진주** — 크고 작은 진주를 1~2알. 리본·레이스와 세트로.
- **입체 장미(아크릴 플라워)** — 포인트 손톱에 딱 1개.
- **별 모양 젤리 파츠, 리본 캐스팅, 단추(!) 같은 위트 오브제** — 손 전체에 1곳만.
- 규칙: **"파츠는 한 손에 1~2 포인트, 나머지는 평면 아트"** — 과적 금지.

### 2-6. 쉐입 & 길이
- **아몬드(라운드 포인티드)** 미디엄~롱이 기본 (팁 사진 대부분).
- 착용샷은 **롱 스퀘어/코핀**도 등장 (IMG_6094, 6097, 6098) — 쉐입은 유동적이되
  아트 문법은 동일하게 유지됨.

### 2-7. 세트 구성 방식 (10개 손톱 연출)
- **"통일된 테마 + 손톱마다 다른 변주"**: 같은 팔레트/모티프 안에서 5개 손톱이
  전부 다른 디자인 (도트팁 / 레터링 / 스트라이프 / 파츠 / 민무늬 누드).
- 반드시 1~2개는 **거의 빈 누드 손톱**을 섞어 리듬을 만든다.

## 4. 생성용 마스터 프롬프트 (영문)

이미지 생성 모델(예: gpt-image, Imagen, SDXL 등)에 그대로 넣는 베이스 프롬프트:

```
Korean-style press-on nail set, medium-long almond nails,
sheer milky nude base with high-gloss gel finish,
deep French tips filled with {PATTERN} in {PALETTE},
each of the 5 nails a different variation on the same theme,
one nearly-bare nude accent nail, one nail with {POINT},
delicate hand-painted look, kawaii coquette Y2K mood,
clean studio photo on plain light-grey background, top-down flat lay
```

슬롯 값:
- `{PATTERN}`: polka dots / thin stripes / pastel gingham check / hand-drawn swirls / lace frill edge
- `{PALETTE}`: baby pink + baby blue / butter yellow + sky blue / white + black accents / lilac + white
- `{POINT}`: cursive "Angel" script lettering / one 3D acrylic rose / tiny silver ball studs / a pearl and ribbon / star-shaped gems

### 스타일 고정 네거티브(피해야 할 것)
```
no neon colors, no full-coverage dark polish, no heavy glitter all over,
no more than 2 charm points per hand, no airbrush gradients (unless retro print theme),
avoid crowded design — keep 60% of each nail negative space
```

# 심층 분석 v2 — "왜 예쁜가": 디자이너의 숨은 규칙 역설계

> 1차 분석이 "무엇이 보이는가"였다면, v2는 12장을 관통하는
> **설계 원리·수치 스펙·문화 계보**를 추출한 것. 이달아 생성 엔진의 헌법으로 사용.

## A. 핵심 은유: 손톱 = 옷을 입은 소녀 (팁 = 옷단)

이 디자이너의 모티프는 전부 **반짇고리(재봉함) 어휘**에서 나온다:
- 레이스 트림, 단추(IMG_6097 화이트 단추, IMG_6102 플라워 단추), 리본 캐스팅,
  깅엄·타탄 **원단 패턴**, 도트 **원단 패턴**, 진주(단추/브로치).
- 프렌치 팁 = **치마 밑단**. 그래서 레이스가 항상 "경계선에" 달린다
  (IMG_6100, 6103: 레이스가 팁과 누드의 경계를 따라 스캘럽+피코 드롭 형태로).
- 누드 베이스 = 맨살/속치마. 팁의 패턴 = 옷감.
- **이 은유가 지켜지면 "이 스타일"로 보이고, 깨지면(패턴이 손톱 전체에 흩어지면) 무너진다.**
- 생성 규칙화: 패턴은 반드시 팁 영역에 **가둬라(contained)**. 베이스 위에 뜰 수 있는 건
  레터링·참·단일 플라워뿐.

## B. "한 모티프, 세 가지 재료" (Material Echo) — 통일감의 비밀

같은 모티프를 **다른 재질**로 반복해 세트를 묶는다:
- 별: 손그림 별 ↔ 크롬 별 ↔ 별 모양 젬 파츠 (IMG_6099 3행, IMG_6102 3행, IMG_6103)
- 도트: 페인트 도트 ↔ 실버 볼 스터드 ↔ 진주 — "도트의 3형태" (IMG_6099 4행: 페인트 도트 프렌치 옆에 스터드 도트 프렌치)
- 장미: 3D 아크릴 장미 ↔ 손그림 장미 ↔ 장미 프린트 (IMG_6093, 6100)
- → 생성 시: 세트 테마 모티프 1개를 정하고, 손톱마다 `painted / metal / gem` 중
  다른 재질로 render하게 지시하면 이 효과가 재현됨.

## C. 역할 기반 세트 문법 (5손가락 = 5역할)

12장 모든 세트가 이 구조를 따른다:

| 역할 | 개수 | 내용 | 예 |
|---|---|---|---|
| **앵커(Anchor)** | 1 | 시선 고정: 레터링, 빅참(장미·리본·단추·나비), 풀컬러 | "Angel" 필기체, 3D 장미 |
| **리듬(Rhythm)** | 2~3 | 같은 팔레트의 패턴 변주 (도트/스트라이프/체크) | 도트 프렌치 2종 |
| **쉼표(Rest)** | 1~2 | 거의 빈 누드 + 스터드 0~2개 | 민무늬에 실버볼 1개 |

- 앵커가 2개 이상이면 과해지고, 쉼표가 없으면 답답해진다 — 12장 중 예외 없음.
- 착용샷(IMG_6095, 6098)에서 앵커는 **중지 또는 약지**에 배치 (손 중앙에 시선 고정).

## D. 변주 연산자 6종 — "같은 테마, 다른 손톱"을 만드는 수학

한 테마에서 5개 손톱을 뽑아내는 변환 규칙:
1. **반전(Invert)**: 도형-바탕 색 교환 — 핑크팁×블랙도트 ↔ 블랙팁×화이트도트 (IMG_6098)
2. **스케일(Rescale)**: 마이크로 도트 ↔ 빅 도트 (IMG_6097: 같은 손에 두 크기)
3. **밀도(Density)**: 도트 촘촘 ↔ 성김, 점점 작아지는 도트 트레일 (IMG_6099 1행 2번째)
4. **경계 교체(Boundary swap)**: 스마일라인 ↔ 사선 ↔ 직선 프렌치
5. **재질 교체(Material swap)**: B의 material echo
6. **팔레트 회전(Palette rotate)**: 같은 패턴을 팔레트 내 다른 색으로 (IMG_6104 마지막 행: 스월을 5색으로)

→ 이달아 생성 파이프라인: 테마 1개 + 연산자 2~3개 선택 → 5손톱 플랜 생성. 이게 이 디자이너의 실제 작업 방식과 동형.

## E. 수치 스펙 (생성·검수용 하드 넘버)

- **프렌치 깊이**: 노출 손톱 길이의 30~45% (일반 프렌치 15~20%보다 깊음, 50% 초과는 없음)
- **여백률**: 손톱당 누드 노출 55~70%
- **도트 지름**: 마이크로 0.5~1mm / 표준 1.5~2mm(손톱 폭의 10~15%) / 빅 3mm+ — 한 손톱엔 한 스케일만
- **라인 두께**: 0.5~1mm 가는 선, 2~4mm 간격, 한 손톱에 2~4줄
- **파츠 예산**: 손 전체 빅참 1개 + 미니 스터드 3~6개. 한 손톱에 스터드 최대 3개
- **팔레트 예산**: 뉴트럴 1 + 파스텔 2~3 + 다크 악센트 0~1 (합계 4~5색 상한)
- **배합비**: 대략 60% 누드 / 30% 파스텔 / 10% 악센트(블랙·브라운·메탈)

## F. 문화 계보 — 이 감성의 뿌리 (IMG_6096 무드보드가 직접 증언)

디자이너가 스스로 밝힌 레퍼런스: **Blythe 인형, 천사 날개+엔젤넘버 555, Angelic Pretty(일본 로리타 브랜드)**, 그리고 크롬하츠 십자가(IMG_6094).
- 계보: 일본 로리타/히메 갸루(레이스·리본·파스텔) × Y2K 키치(크롬·별·레터링) × 서구 코케트/발레코어(진주·리본·누드).
- 감정 포지셔닝: **"소녀 시절 물건들의 아카이브를 어른의 절제로 편집"** — 그리움(nostalgia)과 깨끗함(clean girl)의 동시 충족. 유치하지 않은 이유가 바로 여백 60% 규칙.
